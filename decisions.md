# Decisions: EAT as Reference — Calibrated Classifiers, M2V, Full HF Replacement

| Decision | Alternatives Considered | Rationale |
| :--- | :--- | :--- |
| **COSC fully deprecated — delete all cosc models from HF** | Keep COSC with deprecation notice | User's explicit instruction. Old models were trained on low-quality data. Clean removal avoids confusion for downstream users. |
| **EAT 53-class + 7-class as the two granularities** | Keep COSC 52/6 numbering | EAT has 53 fine-grained labels (adds `BOOL:yesno` vs COSC's 52) and 7 main categories (adds `BOOL` vs COSC's 6). New numbering reflects the actual taxonomy. |
| **Platt sigmoid calibration via `CalibratedClassifierCV(cv=5)`** | Softmax of raw scores; isotonic regression; temperature scaling | Sigmoid is the standard SVM calibration, ONNX-exportable, cv=5 avoids overconfidence from data leakage. Softmax of decision scores is provably miscalibrated. |
| **`zipmap=False` in skl2onnx options** | Default ZipMap output | ZipMap emits sequence-of-dicts; `False` gives plain float32 matrix consistent with existing sentence-type models. |
| **M2V: potion-base 2M/8M/32M only (no multilingual)** | Include multilingual-128M | EAT is currently EN-only. Multilingual potion model would be trained on one language and is wasteful. Revisit when EAT expands to other languages. |
| **M2V at both 7-class and 53-class** | 7-class only (matching old COSC 6-class m2v) | Old m2v was 6-class only due to COSC dataset limits. EAT data quality supports fine-grained 53-class m2v training. |
| **New script `train_eat_m2v.py` separate from `train_eat.py`** | Single script with `--m2v` flag | M2V training requires `model2vec` package and has different dependencies, longer runtime, and separate save format. Keeping it separate maintains the ONNX-only guarantee for `train_eat.py`. |
| **`EatClassifier` replaces `QuestionTypeClassifier`** | Keep `QuestionTypeClassifier` name pointing to EAT | Clean rename signals the taxonomy change. Any existing code importing `QuestionTypeClassifier` gets a clear deprecation path. |
| **`Sentence.classification_scores` + `.confidence` on public API** | Internal only; expose via separate method | Confidence is a first-class feature requested for use within little_questions. Direct property access is consistent with existing `.classification`, `.sentence_type`, etc. |
| **Delete 19 COSC question-type scripts; keep all sentence-type scripts** | Keep with deprecation notice | Every deleted script either trains on COSC data, translates COSC data, benchmarks COSC models, or validates COSC exports. None have EAT utility. Hard deletes keep the codebase unambiguous. `metrics.py`, `baselines.py`, `mlflow_config.py`, `eval_sentence_type.py`, and `lang/` are generic and stay. |
| **New HF repo `TigreGotico/eat-classifiers`; leave `TigreGotico/sentence-types` untouched** | Push everything to sentence-types; or create a single merged repo | Clean separation: each HF repo maps to one task and one source dataset. sentence-types ↔ `TigreGotico/sentence-types-multilingual`; eat-classifiers ↔ `TigreGotico/EAT`. |
| **README references both source datasets explicitly** | List datasets inline without links | Both `TigreGotico/EAT` and `TigreGotico/sentence-types-multilingual` were built specifically for this project. Linking them makes the provenance clear and drives discoverability on HuggingFace Hub. |
| **Rewrite README + BENCHMARKS from scratch** | Append EAT section, mark COSC deprecated | User explicitly asked not to mention old models. Rewrite avoids accidental references and makes the HF model card accurate for new users. |
